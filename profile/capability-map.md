# 能力地图

| 领域 | 主要能力 | 使用方式 |
|---|---|---|
| 具身智能 | ROS 2、Gazebo、MoveIt、SimReady 资产、策略示教与安全执行 | 分离外观/碰撞/物理/适配器，以仿真/规划/控制的独立证据判定完成，并对齐 observation/state/action 与统一控制权 |
| 物理 AI 数据 | 设备 BOM、存储模型、数据价值验证、BP | 来源可追溯，计算可重算 |
| Web 交付 | React/Next.js、数据恢复、测试、部署验收 | 复现真实流程后修复，以版本、应用/数据库健康和安全恢复共同验收发布 |
| 工程治理 | 项目内 Skill、远程 handoff、Git/子模块作用域 | 先加载项目规则，按检查点执行，并分层验证静态、运行时与闭环证据 |
| Agent 执行安全 | 候选意图、schema 校验、能力白名单、执行端口 | 生成式模型不持有授权；provider 失败与语义失败分开处理 |
| 实验治理 | 长时任务账本、多后端迁移、运行 provenance | 隔离来源、后端和生命周期，按当前批次合同判定资格 |
| 并行编排 | 队列、租约、Worker/Broker 生命周期、逐级准入、恢复与资格 | coordinator 持有批次权威，独立 authority 裁决可复用画像；精确容量、代际指标和封存证据不足时 fail closed |
| 测试治理 | 日常快速门、低频基准、分区契约、环境 provenance | 默认门保持快速，按变更范围显式运行基准并确认真实发现用例 |
| GUI 取证 | macOS/GNOME 窗口识别、权限归因、配色验收、精确截图 | 绑定当前窗口与运行制品，使用本轮受影响状态截图，拒绝全屏、裁剪或旧证据替代 |
| 研究资产 | Obsidian、论文分析、商业投资研究、来源整理 | 分开事实、作者实验、复现、估值口径、可交易边界、证伪条件与待验证项 |
| 数据契约 | 原始数据、规范化数据集、模型视图、模板/schema 迁移 | 保留原始层，冻结契约，并用代表性样本回读验证 |
| 协作资料 | 飞书文档、云盘、表格、幻灯片 | 明确内容源，整篇同步后重新回读验收 |
| 制品交付 | 模型、数据集、PDF 与物理打印 | 以 manifest/哈希选择与回读数字制品，以内容/队列/设备状态验收打印 |
| 远程维护 | Xray、Tailscale、SSH、Codex 连通性 | 只同步无凭据受管输入，保留目标机配置与恢复路径并做真实验证 |
| 系统与设备维护 | CLI/daemon 分层诊断、固件版本核对与受控升级 | 先做只读身份和兼容性检查，高风险动作需授权，并从最终界面或设备功能复验 |
