# 能力地图

| 领域 | 主要能力 | 使用方式 |
|---|---|---|
| 具身智能 | ROS 2、Gazebo、MoveIt、Panda 状态机与验证 | 以仿真/规划/控制的独立证据判定完成 |
| 物理 AI 数据 | 设备 BOM、存储模型、数据价值验证、BP | 来源可追溯，计算可重算 |
| Web 交付 | React/Next.js、数据恢复、测试、部署验收 | 复现真实流程后修复和发布 |
| 工程治理 | 项目内 Skill、远程 handoff、Git/子模块作用域 | 先加载项目规则，按检查点执行，并分层验证静态、运行时与闭环证据 |
| Agent 执行安全 | 候选意图、schema 校验、能力白名单、执行端口 | 生成式模型不持有授权；provider 失败与语义失败分开处理 |
| 实验治理 | 长时任务账本、多后端迁移、运行 provenance | 隔离来源、后端和生命周期，按当前批次合同判定资格 |
| GUI 取证 | macOS/GNOME 窗口识别、权限归因、精确截图 | 绑定当前窗口身份和原始内容，拒绝全屏、裁剪或旧证据替代 |
| 研究资产 | Obsidian、来源整理、结构化文档 | 将事实、作者实验、复现、商业证据与待验证项分层沉淀 |
| 数据契约 | 原始数据、规范化数据集、模型视图、模板/schema 迁移 | 保留原始层，冻结契约，并用代表性样本回读验证 |
| 协作资料 | 飞书文档、云盘、表格、幻灯片 | 明确内容源，整篇同步后重新回读验收 |
| 远程维护 | Xray、Tailscale、SSH、Codex 连通性 | 只同步无凭据受管输入，保留目标机配置与恢复路径并做真实验证 |
