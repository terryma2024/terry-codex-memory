# 任务工作流

## 机器人与仿真

1. 定义每个系统的权威边界：仿真世界、规划场景、控制器和真实状态查询。
2. 先以最小动作复现，并写出预期结果。
3. 分别验证规划、执行、物体附着、碰撞场景和关节/TF 事实。
4. 仅在验证成功后推进状态；失败按已产生的副作用恢复。

## 研究、数据业务与 BP

1. 记录原始来源与时间。
2. 抽取可验证事实，并单列推断、访谈说法与待验证假设。
3. 映射到当前产品、客户、技术、成本或 BP 缺口。
4. 形成带来源的可复用文档；同步时以指定在线版本为权威。

## 生产修复与发布

1. 只读定位并复现真实问题。
2. 选择最小改动，补充回归覆盖。
3. 在本地运行相关质量门。
4. 发布后按真实用户路径验收，记录证据与残余风险。

## 远程网络与主机

1. 先确认连接、代理、进程和有效环境变量。
2. 保留独立恢复路径，备份将修改的配置。
3. 只做必要的局部修改。
4. 通过真实外部请求验证，并避免在输出中泄露路径、凭据或私有配置。
