# thinking-partner

这是用于决策澄清与目标探索的自建 Skill。它将对话保持为苏格拉底式过程：每轮只问一个问题，先确认真正目标、动机、成功标准、约束与锚点，再讨论方案。

## 适用场景

- 目标仍不清晰，或存在多个互相竞争的目标。
- 需要做重要选择，但不希望太快跳到执行方案。
- 希望识别“手段”与“真正目标”之间的差异。

## 不适用场景

对已经清楚、可直接执行的工程任务，不应阻塞执行；只有用户明确希望先澄清目标时才使用。

## 安装

将本目录复制到目标 Codex 的可发现 Skill 目录，刷新任务后使用 `$thinking-partner` 调用。
