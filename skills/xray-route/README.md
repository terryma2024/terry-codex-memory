# xray-route：可移植说明

这是一个已由真实任务验证的自定义 Codex Skill。它被作为参考源码保存在本仓库，但**不会自动安装**。

## 前置条件

- 新机器已经自行安装并验证了 Xray。
- 新机器存在经过安全审查的 `xray-direct`、`xray-proxy` 与 `xray-route` 命令。
- 规则文件、服务管理方式和凭据均在新机器本地配置。

## 安装方式

将本目录复制到目标 Codex 的可发现 Skill 目录；然后重新启动或创建新任务以刷新 Skill 发现。安装前应先替换/核对本 Skill 中与操作系统和服务管理相关的命令。

## 安全限制

- 不要提交真实路由名单、Xray JSON、订阅地址或凭据。
- 不要绕过命令自身的配置测试和连通性验证。
- 若“白名单”含义不清，必须先确认是 DIRECT 还是 PROXY。
- 强制整个域名家族走 PROXY 时，向配套命令传裸根域；例如用户写 `*.example.org`，命令参数应为 `example.org`，并在变更后核对 PROXY 清单中的裸根域。
- DIRECT 的通配规则仍以目标机器实现为准；安装到新机器前必须重新确认其覆盖范围。
