# vocab-print-cards

这是用于生成 A4 中译英默写卡和独立答案页的自建 Skill。它将词汇表生成可打印 PDF，并要求打印前先渲染检查版式。

## 依赖

- Python 3。
- ReportLab；目标 Codex 的捆绑 Python 或本机环境必须已提供它。
- 可选：`pdftoppm` 用于 PDF 渲染检查，CUPS 工具用于实际打印。

## 安装与验证

1. 将本目录复制到目标 Codex 的可发现 Skill 目录。
2. 在目标机器为 ReportLab 配置合规的 Python 环境。
3. 使用一组非敏感示例词汇生成 PDF，并人工检查渲染结果。
4. 只有用户明确要求时才连接和使用打印机。

## 安全边界

词汇输入和生成 PDF 可能包含学习材料；只保存在当前任务输出目录，不要作为全局日志或未经确认的云端数据上传。
